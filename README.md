# Yüksel Mahmutoğlu — Portföy

Üretken yapay zekâ, içerik üretimi ve otomasyon çalışmaları.

Site: https://protocol272.github.io/portfolio/

Statik HTML, CSS ve JavaScript. GitHub Pages, `main` dalının kök dizininden yayımlar. `.nojekyll` dosyası statik dosyaların doğrudan sunulmasını sağlar.

Güncelleme için `index.html`, `styles.css`, `app.js` ve gerektiğinde `assets/` dosyalarını güncelleyip `main` dalına commit gönderin. Yayın GitHub Pages üzerinden otomatik yenilenir.
